## 1. 背景与总体架构

知识库全量外置 RAGFlow。nl2sql 后台「知识库」tab 目前只有最简转发（配置+勾选库+单文件上传），要升级为完整管理页；同时使用方要求：**日常操作知识库的人不该碰到 RAGFlow 连接配置（api_key / server 地址）**，因此引入第二个账号做权限隔离。

```
┌─ nl2sql（页面+后端一体） ──────────────────────────────┐
│ 管理后台「知识库」tab（升级为完整管理页）                  │
│   ├ 连接配置区：base_url / api_key（仅 admin 可见可改）    │
│   └ 管理区：库列表 / 文档管理 / 上传(本地+EAM) / 启停 / 进度 │
│ 账号体系（auth 升级为多账号）                             │
│   ├ admin：全权（现有单账户语义不变）                      │
│   └ kb_op（知识库操作员，新增）：只能进知识库 tab，          │
│      连接配置不可见，其余 tab 全部锁定                      │
│ 后端新增/扩展                                            │
│   ├ RagflowClient：文档启停等（见 4.1）                   │
│   ├ admin_ragflow 扩展 + admin_eam 新增                   │
│   └ 接口角色校验：kb_op 只放行知识库管理端点               │
└────────────────────┬────────────────────────────────────┘
                     │ 同一 RAGFlow 账号（nl_cfg_ragflow 表既有连接，不变）
                     ▼
             ┌──────────────┐
             │   RAGFlow    │  （启停/建库/上传都落在 RAGFlow，无自建状态表）
             └──────────────┘
```

**要点**：管理页面与 nl2sql 检索（knowledge_search）天然同源同账号——启停即时影响检索范围（默认全部库，见第 6 章）。RAGFlow 仍是唯一事实源，nl2sql 除账号外不新增任何数据表（EAM 对接配置走 yml、dqtoken 前端透传，见 4.4）。

## 2. 目标与非目标

**目标**

1. nl2sql 后台「知识库」tab 升级为完整管理页（入口不变，无需新菜单）
2. 新建知识库（选解析方式，默认通用）
3. 上传文档（**唯一上传入口**）：来源二选一——**本地文件 / EAM 文档树**；目标库可多选——同一文档一次进多个库（各库独立一份）；RAGFlow 不支持的格式自动拦截（本地）或隐藏（EAM 树）；解析进度展示（文件级进度条 + 库级汇总，3s 轮询）
4. 文件级启用/禁用开关；库级启停 = 批量翻转库内全部文件（覆盖式，不记忆单文件状态）
5. EAM 打通（上传弹窗的「EAM 文档管理」来源）：只读浏览 EAM **文档树** → 勾选文件或整个文件夹（子树全选）→ 选目标库同步（后端拿 dqtoken 逐个下载 → 传 RAGFlow → 自动解析）；同一文件可进多个库，不去重
6. **多账号与权限**：新增「知识库操作员」账号——登录后只能进知识库 tab 管理知识库；**RAGFlow 连接配置（api_key / server 地址）对其不可见不可改**；其余后台 tab 全部锁定
7. nl2sql 检索：默认全部库（去掉「勾选参与检索的知识库」勾选），启停即时生效

**非目标（明确不做，防蔓延）**

- 不做 EAM 定时自动同步 / 增量比对
- **绝不向 EAM 发任何写请求**（只读红线）
- 不做同步去重（同名中性提示，不拦截）
- 不做按库差异化检索参数（top_k / 相似度门槛仍是全局一份）
- 不做完整 RBAC（就两个角色：admin / kb_op，写死；以后要细分再说）
- kb_op 的鉴权粒度到 tab 级即可，不做到按钮级（连接配置整卡隐藏就满足了「不能动 apikey/地址」）
- EAM 对接配置进 yml 不进表；**除可能的账号存储外不新增任何数据表**（账号走 yml，见 4.4）

### 3.2 状态 × 启用 二维语义（写死防歧义）

`run`（解析进度）和 `enabled`（启用开关）是**两个独立维度**：

| | enabled=on | enabled=off |
|---|---|---|
| **run=DONE** | ✅ 参与检索 | 已解析但不召回（行置灰） |
| **run=RUNNING** | 解析完成后才可召回 | 解析完也不召回（行置灰） |
| **run=UNSTART** | 未解析，不可召回（「解析」按钮） | 同左，行置灰 |
| **run=FAIL** | 不可召回，红色进度条 + 悬浮看失败原因 + 「重新解析」 | 同左，行置灰 |

### 3.3 开关语义

- **文件级开关**（每行手写开关）：点击 → 调启停接口（单文件）；off 的行整体置灰（CSS opacity .5）
- **库级开关**（库列表每行 Switch）：confirm 提示「将把该库 N 个文件全部禁用/启用，覆盖现有单文件开关状态」→ 批量接口 → 刷新①②。**不记忆**：再启用时之前单独禁掉的文件也会被一起打开（已确认）
- 库开关显示态 = 该库全部文件 enabled 的聚合（全 on 才显示 on）

### 3.4 进度与轮询

- RUNNING 进度条（`Progress` 组件，`progress×100%`，蓝色）；DONE 绿色满格（`status="success"`）；FAIL 红色（`status="exception"`，悬浮 Tooltip 显示 `progress_msg`）；UNSTART 灰字「未解析」
- 轮询：任一库解析中或选中库存在 RUNNING 文档时，每 **3s** 同刷①（`GET /datasets?include_parsing_status=true`）与②（`GET /datasets/{id}/documents`）
- 停止：无 RUNNING / 组件卸载（`useEffect` 清理函数清定时器）/ 切换选中库 / 10 分钟上限（留手动「刷新」）
- 上传 / EAM 同步成功后立即手动刷一次并启动轮询

**进度轮询**（对应 3.4，原生 JS）：

```js
// 与原型同款：hasRunning 由数据推导，无 RUNNING 自动停，10 分钟上限
let pollTimer = null, pollStart = 0;
function startPolling() { if (!pollTimer) { pollStart = Date.now(); pollTimer = setInterval(tick, 3000); } }
function stopPolling() { clearInterval(pollTimer); pollTimer = null; }
async function tick() {
  if (Date.now() - pollStart > 10 * 60 * 1000) return stopPolling();
  await Promise.all([loadDatasets(), loadDocs()]);   // 库汇总 + 当前库文档，一个 tick 并行
  if (!anyRunning()) stopPolling();
}
```

**角色渲染**：登录后 token 携带 role（见 4.3），前端 `showSettings()` 时按 role 渲染——kb_op 隐藏连接配置卡（不渲染 DOM，而非 CSS 隐藏）、其余 stab 置灰不可点。

**原型说明**：[原型-知识库管理.html](原型-知识库管理.html) 外壳与组件即为实现基线（本轮已换回 nl2sql Material 配色 + 设置页外壳 + 身份切换演示），实现时组件代码直接搬。

| 既有 documents/parse/config 端点 | 不动（config 的 dataset_ids 字段标废弃） |

EAM 同步时序（单请求内，逐 (文件×库) 容错）：

```
aborted = false
for 文件 f:                     # ≤20 个（前端硬限）
  for 库 d:
    if aborted: results += {f, d, ok:false, error:"dqtoken 已过期"}; continue
    try:
      name, bytes = EAM 下载(f.id)                 # 300s 超时，仅 GET
      RAGFlow 上传(d, name, bytes) → 触发解析(d)
      results += {f, d, ok:true}
    except EamTokenExpiredError: aborted = true; results += {f, d, ok:false, error:"dqtoken 已过期"}
    except Exception as e: results += {f, d, ok:false, error:str(e)}，继续
return {results, ok_count, fail_count}
```

不搞后台任务：同步本身快（内网下载+上传），慢的是 RAGFlow 解析——解析进度由文档列表 3s 轮询自然展示。`# ponytail:` 单批经常超浏览器超时再升级 BackgroundTasks。

### 4.3 多账号与角色（`src/config.py` auth 段 + 认证链路升级）

**账号配置（yml，不建表）**：

```yaml
auth:
  # 兼容旧单账户：auth.password 存在时视为 admin 账号
  accounts:
    - { username: admin,  password: "现有密码", role: admin }
    - { username: kbop,   password: "发给操作员的密码", role: kb_op }   # 知识库操作员
```

**认证链路**：登录接口校验 accounts → 签发**带 role 的 hmac token**（现有无状态签名机制扩一个字段）→ 前端存 localStorage；`Authorization: Bearer` 校验时解析 role。

**接口角色校验矩阵**（后端强制，前端隐藏只是体验）：

| 端点组 | admin | kb_op |
|---|---|---|
| `/api/ask`（问数/聊天） | ✅ | ✅ |
| `/api/login` | ✅ | ✅ |
| `/api/admin/ragflow/datasets`、`documents*`、`parse`、`documents-enabled` | ✅ | ✅ |
| `/api/admin/eam/*` | ✅ | ✅ |
| `GET/PUT /api/admin/ragflow-config` | ✅ | ❌ 403「无权限：知识库操作员不能查看/修改 RAGFlow 连接配置」 |
| 其余全部 admin 端点（数据源/提示词/模型/飞书/统计/上限…） | ✅ | ❌ 403 |

## 5. RAGFlow API 映射与支持格式

| 功能 | 端点 | 关键请求 | 关键响应字段 |
|---|---|---|---|
| 列知识库 | GET /api/v1/datasets?include_parsing_status=true | — | document_count / chunk_count / unstart_count / running_count / cancel_count / done_count / fail_count |
| 建库 | POST /api/v1/datasets | `{name, description?, chunk_method?}` | dataset 对象（id） |
| 列文档 | GET /api/v1/datasets/{ds}/documents | — | run(UNSTART/RUNNING/CANCEL/DONE/FAIL) / progress(0~1) / progress_msg / chunk_count / **enabled** |
| 上传 | POST /api/v1/datasets/{ds}/documents | multipart `file=@`（可多文件） | document 对象（id, run=UNSTART） |
| 触发解析 | POST /api/v1/datasets/{ds}/chunks | `{"document_ids":[...]}` | code=0 |
| **文档启停** | PUT /api/v1/datasets/{ds}/documents/{doc} | `{"enabled": 0或1}`（int） | code=0 |
| 删除文档 | DELETE /api/v1/datasets/{ds}/documents | `{"ids":[...]}` | code=0 |
| 检索 | POST /api/v1/retrieval | `{question, dataset_ids, top_k, ...}`（**dataset_ids 至少一个，不传报错**） | chunks[] |

**页面功能 ↔ RAGFlow API 支持性对照（全部支持，零自建存储）**：

| 页面功能 | API | 支持性 |
|---|---|---|
| 库列表 + 解析汇总 | GET /datasets?include_parsing_status=true | ✅ 原生 |
| 新建库 | POST /datasets | ✅ 原生 |
| 文件列表 + 进度 | GET /datasets/{id}/documents（run/progress/progress_msg） | ✅ 原生 |
| 上传（多文件） | POST /datasets/{id}/documents multipart | ✅ 原生 |
| 触发/重新解析 | POST /datasets/{id}/chunks | ✅ 原生 |
| 文件级启停 | PUT /datasets/{id}/documents/{doc} `{"enabled":0\|1}` | ✅ 原生（旧版字段名 `status`） |
| 库级启停 | 无库级 API = 文件启停循环 | ✅ 组合实现（设计 4.2 决策 3） |
| 删除文件 | DELETE /datasets/{id}/documents | ✅ 原生 |
| 格式过滤 | RAGFlow 支持列表前端预过滤 | ✅ 无需 API |

**RAGFlow 支持的文件格式**（前端按扩展名预过滤，以部署版本实测为准）：pdf / doc / docx / xls / xlsx / ppt / pptx / txt / md / csv / json / jpg / jpeg / png / gif / bmp / tiff / epub。其余（zip / exe / dwg / cad 图纸等）在 EAM 树中隐藏、本地上传中拦截。

**版本兼容实测清单（上线前跑一遍）**：新版字段 `enabled`，旧版 RAGFlow 是 `status`——先用真实实例测：


## 7. EAM 适配（nl2sql 后端）：已实测打通

> 2026-08-25 通过逆向 EAM 前端 JS（umi 微前端 chunk）+ 真实 token 实测，全部接口验证通过，**无需抓包**。

**EAM 侧事实**：

| 项 | 值（实测） |
|---|---|
| API 网关 | `https://api.gw-greenenergy.com` |
| 鉴权 | 请求头 `loginToken: <dqtoken>`（前端 localStorage `dqtoken` 塞入） |
| 目录树 | `POST /annex/folder/tree`，body `{}` → **一次返回全量树**（前端直接渲染，无需懒加载）；节点字段 id / parentId / name / children |
| 文件列表 | `POST /annex/file/document/list`，body `{parentId, pageNum, pageSize}`；**文件夹与文件混排**，`documentType: "folder"｜"file"` 区分；分页字段在响应顶层（total / current / size）；文件项含 fileId / fileType（pdf…）/ size / version / createdByDesc |
| 下载 | `POST /annex/file/batch/downLoad`，body `{fileDownLoadList: [{id, documentType}], fileName}` → 文件流（单文件直出原文件；批量为压缩包）。实测拉下 221KB / 7 页 PDF 完好 |
| 错误语义 | token 失效/被顶 → `{"code":"403003","name":"TOKEN_REPEAT","message":"您的账号已在其他设备登录"}`（识别此码 → 前端提示重粘） |
| 格式过滤 | 列表自带 `fileType` 字段，服务端过滤比按扩展名猜更准（非 folder 且 fileType ∈ RAGFlow 支持集才显示/可勾） |

**只读红线**：EAM 侧另有 batchUpload / move / batchDelete / recycle / folder 增删等写接口（逆向时已见全量清单）——适配层**只封装上述 3 个读接口**，代码评审核对无任何对 EAM 的写调用；页面不提供任何 EAM 编辑入口。

**⚠ token 互踢风险（重要）**：dqtoken 是**单设备登录态**——用户在浏览器登录 EAM 会把 nl2sql 持有的 token 顶掉（实测遭遇 TOKEN_REPEAT）。缓解：
1. **推荐：申请一个专用账号**（仅用于同步、从不在浏览器登录），token 长期稳定
2. 过渡期：接受偶尔重粘 token（页面有失效提示 + 重粘交互，原型已演示）
3. 不做：服务端模拟登录换 token（涉及账号密码与风控，不做）

## 8. 边界与错误处理

| # | 现象 | 处理 | 用户看到的 |
|---|---|---|---|
| 1 | RAGFlow 旧版不认 `enabled` 字段 | 封装层常量一处切 `status`；按第 5 章清单实测 | 无感 |
| 2 | dqtoken 过期（401/登录页 HTML） | 专属异常中断同步（已传的保留，剩余标失败） | 红字「dqtoken 已过期，请从 EAM 重新复制粘贴」+ 输入框聚焦；结果清单失败项可重选 |
| 3 | 大文件同步慢 | 下载/上传独立 300s 超时；逐项容错不中断批次 | 单项失败原因在结果清单 |
| 4 | 批量启停部分失败 | 逐项容错返回 failed 明细 | 「已更新 14/15，1 个失败：xxx.docx（原因）」 |
| 5 | 重复同步/上传同一文件到同一库 | 不拦截不去重（支持同一文档多库并存），弹窗中性标注 | 「该库已有同名，将再添加一份」 |
| 6 | 解析失败 | FAIL 红条 + 悬浮 `progress_msg` + 「重新解析」 | 失败原因可见可重试 |
| 7 | nl2sql 存量：检索范围扩大到全部库 | 预期行为，发布知会 | 无感 |
| 8 | EAM 未配置/未抓包 | 端点返回 400「EAM 未配置」；页面隐藏 EAM 入口 | 无感 |
| 9 | 多端同时操作 RAGFlow（nl2sql 后台 + RAGFlow 控制台） | RAGFlow 是唯一事实源，页面每次现查 | 刷新即最新 |

| 11 | yml 未配 eam 段 | EAM 来源入口不渲染；端点返回 400「EAM 未配置」 | 无感 |
