NL2SQL AI 问数 · 端到端问答流程

用户提问 → 名称纠错 → ReAct 自主循环（LLM↔工具）→ SSE 流式回流 → 审计/结果旁路

主链路（同步阻塞用户）

  • 浏览器 POST → Orchestrator 纠错+规则+prompt
  • AgentLoop ReAct：LLM 决策→工具→回灌，循环
  • execute_sql 走 SQL 护栏（sqlglot 拦 DDL/DML + 30s 超时 + 1 万行）
  • finish 结束 / ask_user 挂起等用户补信息

流式与旁路（不阻塞）

  • SSE 边算边吐：answer_delta 打字机、correction 纠错提示
  • 大结果走 result_id 旁路（不灌 LLM），前端按 id 拉表 + 导 Excel
  • 审计 events/traces 异步落库，挂了不毁主链路
  • LLM 网关限流：jitter + retry-after + 并发闸/RPM 窗

归因 vs 取数

  • 取数：query_metadata 选表 → execute_sql 查
  • 归因（为什么）：do_attribution 取知识库文档 + 维度框架 → 配合 execute_sql 查量化 → 主因/次因/依据分层
  • 口径/政策：knowledge_search 直接检索文档
  • 无数据/无文档如实告知，不编造
